# Patinhas do Bem 🐶

## Sobre o projeto
O Patinhas do Bem é um site criado para ajudar cachorros em situação de rua a encontrarem um novo lar.

## Objetivo
O objetivo do projeto é incentivar a adoção responsável e ajudar animais resgatados.

## Tecnologias utilizadas
- HTML
- CSS
- GitHub

## Funcionalidades
- Página inicial
- Informações sobre adoção
- Imagens de cachorros
- Página de contato
